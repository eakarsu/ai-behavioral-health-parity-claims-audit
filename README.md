# Behavioral Health Parity Claims Audit

Detect parity failures and quantify member, reimbursement, and regulatory exposure across quantitative and nonquantitative treatment limits.

**Primary buyer:** Health plans, employers, and behavioral-health administrators. **Evidence:** medical and behavioral benefits, NQTL policies, authorization data, network access, claims, denial rates, reimbursement, comparative analyses, and remediation evidence.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Plan classification mapping
- Benefit limit comparison
- NQTL inventory
- Prior authorization comparison
- Concurrent review comparison
- Medical necessity criteria review
- Network admission analysis
- Reimbursement methodology comparison
- Denial rate analytics
- Out-of-network access analysis
- Comparative analysis workbench
- Member impact calculation
- Corrective action workflow
- Regulator evidence package
- Parity governance dashboard

Run `./start.sh`, then open <http://127.0.0.1:4650>. API: `5650`.
